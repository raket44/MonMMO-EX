# Universal warp-trigger rules, one row per region + fixture type. Hot-reloaded - edit and the
# next step uses the new rule, no restart. Rows here OVERRIDE the server's built-in defaults
# (this file ships matching them, so what you see is what runs).
#
#   region;type;fire;press;arrival
#
#   GBA arrivals step off DOORS only (field_fadetransition.c SetUpWarpExitTask: Task_ExitDoor for
#   a door tile, Task_ExitNonAnimDoor for a cave mouth, Task_ExitNonDoor - no walk - for all else).
#   Interior door MATS are SOUTH_ARROW_WARP tiles in both FireRed and Emerald, so arrow arrivals
#   REST: the cutscenes that meet you at the door (Six Island's rival) are laid out for the mat.
#   (2026-09-08 had arrows STEP after the S.S. Anne gangway faded to black on a rest; if that
#   returns, retune that one tile with an 8-field row, not the type.)
#
#   region : 0 Kanto, 1 Hoenn, 3 Sinnoh, 4 Johto (2 Unova needs no rows - its warps carry
#            their own directions from the ROM)
#   type   : Gen 4 = the ROM tile-behavior byte (decimal, names from the decomps);
#            GBA   = the TileBehavior name
#   fire   : STAND   = fires only pressing <press> while STANDING on the tile (walkable
#                      fixtures - lets the client animate the step first, then fires in sync)
#            STEP    = fires stepping TOWARD the tile with <press> (impassable doors)
#            CONTACT = fires stepping onto the tile from any direction (panels, escalators)
#   press  : UP / DOWN / LEFT / RIGHT, or - for CONTACT
#   arrival: REST = arrivals stay on the landing tile; STEP = walk out one tile.
#            LIVE FOR ALL REGIONS. The landing tile's rule also sets the exit FACING:
#            its <press> reversed (land on a press-UP door = walk out DOWN), which is
#            exactly vanilla's GetAdjustedInitialDirection table on every region.
#
# ONE SINGLE WARP can also get its own rule - add an 8-field row and it beats the type rule:
#
#   region;bank;map;x;y;fire;press;arrival
#
# e.g.  4;222;0;6;6;STAND;LEFT;REST   would retune just that one tile in that one map.
