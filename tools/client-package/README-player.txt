MonMMO-EX client
================

1. Unzip this folder anywhere (for example your Desktop). Keep everything together.
2. Double-click MonMMO-EX.exe. Windows may warn about an unknown publisher the first
   time; choose "More info" > "Run anyway".
3. The game asks for your ROMs the first time, exactly like retail: point it at your own
   Fire Red, Emerald, HeartGold/SoulSilver, Platinum and Black/White files. (You can also
   drop them in the "roms" folder first and pick them from there.)
4. Log in with the account name and password you were given. There is no account
   creation on the login screen; the server owner makes the account.

It is already pointed at our server (config\zzz-monmmo-ex-server.properties). If the
server moves, edit the two host lines in that file.

The MonMMO-EX expansion content (extra species, forms and items) is built in: the
"monmmo-lost-knights" mod under data\mods is enabled and must stay enabled.

Do not try to play on the official PokeMMO servers with this client.
