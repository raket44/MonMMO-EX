**ZzPSYCHOzZ, EikoBiko and Flygs** (https://forums.pokemmo.com/index.php?/topic/196915-), used with
the authors' permission (owner confirmed, 2026-09-17).

from its stock yellow to the same cyan, so only this one file comes from elsewhere.
