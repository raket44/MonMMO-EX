# Client 31914 packet map

Server-to-client opcodes, resolved from the client's own registry (`f/E1`) by following each
`invokedynamic` back through the bootstrap-method table to the packet class it constructs.
Verified against ground truth: `0x02 -> f/LG1` is the character list, which matches the class
named in a real parse failure, and `0x1C`/`0x1D` are the two Pokedex packets.

Client-to-server opcodes come from `f/Mw1`; the two spaces are independent, so a request and its
reply do not share a number. Known: **c2s 122 = `f/dK0`**, the empty National Pokedex request
that the server currently never answers.
