# Sprite pack credits

Art in this directory is used on the owner's private, non-commercial server. Every source below
asks for attribution; this file is that credits page and must ship with any client that carries
the art.

## Showdown Gen 5-style set (`showdown/`)
Pokémon Showdown's `gen5`, `gen5-shiny`, `gen5-back`, `gen5-back-shiny`, `gen5ani`,
`gen5ani-back` — the Smogon Sprite Projects (XY, SM, SwSh, SV) and every contributor listed in
their threads. Non-profit use with credit and a link back:
- https://www.smogon.com/forums/threads/xy-sprite-project.3486712/
- https://play.pokemonshowdown.com/sprites/

## EBS Gen 6+7 animated battlers (`ebs-gen67/`)
"Pokemon Essentials EBS Gen6+Gen7 ANIMATED Sprites" compiled by Sturdy-Ghost (DeviantArt), from
the DeviantArt BW-style animators (Diegotoon20, Creobnil and others credited in the pack's
thread). Terms: free to use in games with this credit and the source links.
- https://www.deviantart.com/sturdy-ghost/art/Pokemon-Essentials-EBS-Gen6-Gen7-ANIMATED-Sprites-790085990
- https://reliccastle.com/resources/291/
